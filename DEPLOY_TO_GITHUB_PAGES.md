# Deploy HandEdit V2 to GitHub Pages

This folder is deployment-ready. `index.html` must stay at the repository root.

## Option A — Project site

Repository name: `HandEdit`

Resulting URL:

`https://YOUR_GITHUB_USERNAME.github.io/HandEdit/`

1. Create a new GitHub repository named `HandEdit`.
2. Upload **the contents of this folder** to the repository root. Do not upload the enclosing folder as an extra level.
3. Open repository `Settings` → `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for Pages deployment to complete, then open the URL above.

## Option B — User site like maniptrans.github.io

Repository name must be:

`YOUR_GITHUB_USERNAME.github.io`

Resulting URL:

`https://YOUR_GITHUB_USERNAME.github.io/`

Upload the contents of this folder to the repository root, then enable Pages from `main` / `/(root)`.

## Important for anonymous review

Do not use a personal GitHub username, lab account, university account, personal domain, analytics ID, or identifiable repository metadata if double-blind anonymity still applies. Use a hosting identity and workflow that do not reveal authorship, and keep the code button pointed at the anonymous repository mirror.
