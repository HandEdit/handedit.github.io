# Teaser media

Production files:

- `teaser.mp4`: 1920x1080 H.264 project teaser with an embedded AAC music track and fast-start metadata.
- `teaser-poster.jpg`: the 1920x1080 cover supplied with the final teaser package.

The final MP4 embeds the opening section of [**Forest Mist Whispers**](https://mixkit.co/free-stock-music/tag/meditation/) by Alejandro Magaña (A. M.) from Mixkit (track ID 148). The background track is mixed at reduced gain with a 0.6-second fade-in and 1.2-second fade-out, so it stays secondary to the visual content and playback does not depend on a third-party request.

If the video is replaced later, retain an H.264/AAC MP4, a 16:9 poster, and captions whenever essential speech is introduced.
