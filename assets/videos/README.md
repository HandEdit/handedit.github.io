# Teaser video

Place the final project teaser at:

`assets/videos/teaser.mp4`

Recommended delivery format:

- MP4 container with H.264 video
- 16:9 aspect ratio, ideally 1920x1080
- Web-optimized / fast-start encoding
- Captions should be added if the final video includes essential speech

The page uses `assets/figures/fig1-teaser.webp` as the poster and social sharing image. The temporary poster overlay disappears automatically when `teaser.mp4` can play.
