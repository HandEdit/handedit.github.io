# Teaser media

Production files:

- `teaser.mp4`: 1920x1080 H.264 project teaser with an embedded AAC music track and fast-start metadata.
- `teaser-poster.jpg`: the 1920x1080 cover supplied with the final teaser package.

The music referenced by the supplied player is **Spanish Heart** by Michael Ramir C. from Mixkit. The final MP4 embeds the opening section locally, using the same low-pass and gain settings as the supplied player code, so playback does not depend on a third-party request.

If the video is replaced later, retain an H.264/AAC MP4, a 16:9 poster, and captions whenever essential speech is introduced.
