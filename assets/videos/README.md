# Teaser media

Production files:

- `teaser.mp4`: 1920x1080 project teaser with its final embedded soundtrack.
- `teaser-poster.jpg`: the 1920x1080 cover supplied with the final teaser package.

The website plays the audio already embedded in `teaser.mp4`. No separate soundtrack is loaded, mixed, or requested by the page.

If the video is replaced later, retain an H.264/AAC MP4, a 16:9 poster, and captions whenever essential speech is introduced.
